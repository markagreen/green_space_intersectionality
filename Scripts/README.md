# Scripts

There are two files to replicate the analyses:
1. extract_dataset_v2.R - the file gathers all of the datasets required across the North West SDE environment for Cheshire and Merseyside and cleans them into analysis ready versions.
2. intersectionality_analysis_v2.R-  the file combines all of the datasets into a single object, cleans and tidies it further, and then runs all of the analyses reported in the paper. 
3. make_plots_paper.R - the file creates all the figures for the paper. 

All code is written in R.
